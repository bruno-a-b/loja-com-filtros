# Loja Wingbound

Loja Wingbound é um site de catálogo de produtos, inspirado pelo jogo WINGBOUND (na plataforma Roblox) e pelo mangá Attack on Titan, por Hajime Isayama.

## Funcionalidades

- Catálogo de produtos renderizado por meio de funções de Javascript
- Filtragem por preço (mínimo e máximo), região, categoria e barra de pesquisa
- Botão de limpar filtros
- Site de produto (será mesmo?)

## Observações

- Este site utiliza módulos de Javascript, e quando foi testado, a importação não funcionou sem a extensão do Live Server no VS Code.
- Geld é a moeda do jogo.
- Studs é a medida de tamanho/distância no Roblox.
- A nação principal do jogo é dividida em 3 muralhas (Maria, Rose e Sina), onde cada possui 4 distritos.
